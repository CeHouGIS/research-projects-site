01 / Urban representation

Urban Visual Gene

组合探索

将城市景观视作可分析、可重组的高维视觉表征，探索不同视觉成分如何共同构成局部景观。

  • 已有工作多尺度 DINOv3 codebook 与 SAE 特征关系分析。
  • 进展局部组合、关系原型和多尺度原型实验已开展。
  • 下一步验证视觉基因的语义稳定性，并实现加减特征后的可控生成闭环。
Urban Visual Gene 仓库 层级表征代码（私有）

02 / Sparse visual dictionary

Urban Visual Primitives

主实验完成

使用稀疏自编码器从城市街景中识别基本语义模式，比较不同城市的视觉组成与空间分布。

  • 方法DINOv3 ViT-L/16 patch 表征 + BatchTopK SAE（W=4096，K=32）。
  • 进展30 城市主实验与逐维 VLM 候选标注完成；全球城市基线和消融分析已有结果。
  • 待验证独立语义核查、原语稳定性和跨城市 feature 对齐。
代码与实验记录 在线组合结果

03 / Data observation

Fire Description

论文修订

评估火灾边界、建筑 footprint 与人类损毁观测能否在空间和事件上可靠连接，识别野火损毁数据基础中的观测缺口。

  • 研究范围美国 2002–2025 年野火相关观测，分析多源数据匹配与不确定性。
  • 进展论文结构与主要结果已形成；2026-10-03 评论导出中 39/42 个审稿线程仍开放。
  • 重点修改整合流程、数据源优先级、可复现细节和图表仍需完善。

04 / Cross-fire model evaluation

Fire Foundation Model

结果待对齐

评估地学基础模型和多光谱适配方法能否从 PlanetScope 灾前/灾后影像中识别建筑损毁，并迁移到未见火灾。

  • 数据27 场野火、163,312 对建筑 patch；设置 Fire-level LOO 跨火灾测试。
  • 方法MultibandLoRA、Center-Aware Attention，并与 dNBR 物理基线比较。
  • 结果已有多个基准；论文摘要、正文与实验 README 的分数和波段设置仍需统一。

05 / Continuous geospatial infrastructure

Fire Database / GeoLakebase

持续建设

把火灾边界、建筑物、卫星影像、现场损毁标签和模型预测组织成可版本化、可追溯的数据库与分析系统，并研究受约束的 LLM agent 如何监督异步数据流程。

  • 数据系统DuckDB spatial、FastAPI、MapLibre 网页、统一损毁 ontology 和模型 provenance。
  • 论文WildfireDB 稿件提出 agent 负责有边界的流程监督，由确定性程序执行数据处理与写入。
  • 进展数据库、API、网页和仿真评估已形成；数据任务仍在更新，live LLM 评估尚未完成。
  • 最新动态公开网页部署仓库最近更新于 2026-11-01。
