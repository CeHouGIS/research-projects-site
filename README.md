# Ce Hou · Research Projects

研究总览与五个项目子页面：https://cehougis.github.io/research-projects-site/

## 研究方向

- **可解释表征学习（Explainable Representation Learning）**：理解高维表征中的语义与结构，探索可解释、可组合的视觉原语及可控生成。
- **数据缺失条件下的世界模型与基础模型训练（World & Foundation Model Training with Incomplete Data）**：关注不完整观测、缺失模态和稀疏标注条件下的学习、环境建模与泛化。
- **开放世界具身智能（Open-World Embodied Intelligence）**：连接感知表征、环境建模、主动探索与行动反馈，面向未知场景和任务持续学习。

首页“研究方向”区块介绍各方向与现有城市视觉、野火数据和模型研究的联系，以及进一步探索交互与决策的研究目标。

## 任务日历

入口：https://cehougis.github.io/research-projects-site/calendar.html

- 选择日期，填写任务、所属研究项目和可选备注，然后点击“添加任务”。
- 勾选任务后，月历、当天完成率、本月统计和各项目进度会一起更新。
- 支持编辑内容、调整计划日期、按项目或完成状态筛选，以及删除后撤销。
- 点击“导出备份”保存全部任务。另一设备可用“导入备份”恢复；导入会合并任务，同一编号保留更新时间较新的版本。
- 支持通过 `#add-tasks=` 链接添加任务；不保留 URL 片段的浏览器入口可改用 `?add-tasks=`。保存成功后会从地址栏移除任务内容。重复打开不会重置已有任务或完成状态；查询参数方式会随页面请求发送给网站托管服务。
- 页面顶部会显示当前浏览器保存的任务数量；“查看当天任务”“显示全部项目”和“查看最近的任务”可以定位已有记录。手机端先展示当天清单，再展示月历。通过 `?date=YYYY-MM-DD` 可直接打开指定日期。

任务保存在当前浏览器的网站本地存储中，刷新页面会保留；不会提交到 GitHub，不会自动跨设备同步。清理网站数据、使用无痕模式或切换浏览器可能导致记录不可用，建议定期导出备份。本地预览和线上网站是不同的存储空间。

## 本地预览

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

打开 http://127.0.0.1:8766/ 。网站为静态 HTML、CSS 和 JavaScript，无构建步骤，由 GitHub Pages 从 `main` 分支根目录发布。
