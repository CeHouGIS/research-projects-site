04 / Cross-fire model evaluation

Fire Foundation Model

评估地学基础模型和多光谱适配方法能否从 PlanetScope 灾前/灾后影像中识别建筑损毁，并迁移到未见过的火灾。

当前状态论文工作稿，结果待对齐
数据规模27 场野火 / 163,312 对 patch
论文仓库FireDamageFM（私有）

研究问题

单次火灾训练得到的模型容易受到环境、季节、建筑类型和传感器条件变化的影响。这个项目用整场火灾留出测试检验基础模型和多光谱适配能否提升跨火灾泛化。

数据与方法

  • 构建覆盖 27 场野火的 PlanetScope 灾前/灾后建筑 patch 数据集，并以 DINS 五级损毁体系定义标签。
  • 设置 `No Damage` 与 `Destroyed` 二分类任务，同时把 Park、Lahaina 和 Borel 整场作为 held-out test fires。
  • 设计 MultibandLoRA adapter 接入红边和 NIR 波段，并使用 Center-Aware Attention 聚焦中心建筑。

已有结果

  • 历史 within-fire spatial-block benchmark 中，ChangeFormer 达到 Macro F1 0.9517。
  • 论文摘要报告 Fire-level LOO 的 CenterAware 0.8880、dNBR 0.8774；正文和实验 README 还记录了另一组波段对应的 0.8796、0.8803 等结果。
  • 论文指出五级 DINS 损毁尺度受 3 m 影像信息量限制。

当前限制与下一步

摘要、正文和 `fire-damage-map` README 的波段设置与分数还没有完全统一，不能把其中单个分数视为最终指标。

  • 完成多 seed 结果和 Portugal held-out OOD 评估。
  • 统一四波段/六波段/八波段实验表格、数据 manifest 和论文文字。
  • 明确二分类筛查与五级损毁分类各自能够支持的应用场景。

研究快照

  • 27 场野火事件
  • 3 场Fire-level LOO held-out fires
