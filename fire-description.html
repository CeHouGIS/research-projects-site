03 / Data observation

Fire Description

研究火灾边界、建筑 footprint 与人类损毁观测能否在空间、事件和时间上可靠连接，并识别野火损毁数据基础中的观测缺口。

当前状态论文修订
论文题目Wildfire damage science needs an observational infrastructure for the built environment
论文仓库Fire-Description（私有）

研究问题

论文把野火损毁评估看成数据整合问题，关注三类缺口：有建筑而没有损毁标签、有损毁标签而没有匹配建筑，以及无法稳定关联到火灾边界的记录。

数据与分析

  • 整合 2002–2025 年美国野火相关的火灾边界、建筑 footprint 和建筑级人类损毁观测。
  • 通过事件匹配、空间几何匹配、来源优先级和标签协调，评估多源观测之间的对应关系。
  • 结果被定位为数据整合诊断，用于描述覆盖、匹配和时间错位，不直接解释为调查覆盖率或火灾因果效应。

论文贡献

文章提出面向建成环境的野火观测基础设施视角，把火灾边界、时间敏感的建筑清单、地球观测和现场调查放到同一个可审计的证据链中。
