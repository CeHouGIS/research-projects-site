02 / Sparse visual dictionary

Urban Visual Primitives

用稀疏自编码器从城市街景中识别基本语义模式，比较不同城市共享的视觉成分、空间分布和组合关系。

当前状态主实验完成，语义待核查
主实验30 城市 / ViT-L / W4096 / K32
代码urban-visual-gene

研究问题

SAE 能否把高维街景表征拆成一组更容易解释的稀疏视觉单元？这些单元在不同城市中是否有稳定的频率、空间分布和共现关系？

方法与实验

  • 四方向街景经过冻结 DINOv3 ViT-L/16 patch 表征和环形 panorama context mixing。
  • 逐 patch BatchTopK SAE 将 1024 维输入映射到 4096 维稀疏字典，再重建回 1024 维。
  • 逐维提取激活图和 Top 实例，用 VLM 生成可复核的语义候选，并进一步分析 feature 共现和城市相似度。

已有结果

  • 主实验完成 16 轮训练，逐维 VLM 计算已完成。
  • 全球 307 城市路线包含字典宽度、稀疏预算、语义 UMAP、共现显著性和空间检验。
  • 城市相似度、语义 breadth、城市热图和 22 类城市分析已有代码与图件。

待完成验证

当前 feature 名称仍是候选语义。下一阶段需要独立人工或跨模型核查、原语稳定性实验、跨城市 feature 对齐，以及把探索性共现证据转化为可复现的统计结论。

仓库明确提醒：不同 checkpoint 的同编号 feature 不代表同一语义，跨城市比较需要先解决对齐问题。

研究快照

  • 30 城市主实验城市规模
  • 4,096 维SAE 字典宽度
  • K=32BatchTopK 激活预算
